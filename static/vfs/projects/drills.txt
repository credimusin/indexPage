[Project: Drills]
Title:    Drills
Status:   Active Lab Prototype
Platform: Web / Biological RAM Upgrader

Description:
A vocabulary-drilling and spaced-repetition engine engineered to flash
foreign words directly into human long-term memory without causing a
stack overflow.

History & Evolution:
BMO noticed a critical hardware limitation in organic humans: unlike
SQLite, humans cannot simply run 'INSERT INTO brain VALUES ("vocabulary")'
and expect the data to still be there the next morning. Usually, the
human garbage collector wipes 80% of newly learned words during sleep.

Drills was created as a brute-force patch for human memory retention.
Instead of gamified cartoon owls threatening your family if you miss a
streak, it focuses on custom personal dictionaries and relentless,
distraction-free repetition drills until your neural pathways finally
return HTTP 200 OK.

Technical Features:
- Web & PWA Hybrid: Combines a classic server-rendered architecture with
  Progressive Web App capabilities so learners can drill vocabulary in
  elevators, bunkers, or subway tunnels.
- Paranoid CI/CD Pipeline: Guarded by automated GitHub Actions running
  PHPUnit suites, PHPStan at maximum paranoia level, and strict code
  linters so not a single grammar bug slips through.

Usage:
Load your custom dictionary, run the drill loop, and upgrade your
conversational firmware.

Tech stack: PHP 8+, Laravel, PostgreSQL, PWA, PHPUnit, PHPStan.

[Project: imaginal]
Title:      ImaginalOS
Website:    https://namvera.pages.dev/
Repository: https://github.com/credimusin/indexPage
Platform:   Web (8-Bit Potato Cloud)

Description:
An over-engineered retro-futuristic terminal operating system disguised
as a quiet night-sky webpage.

History & Evolution:
ImaginalOS began as a simple question: "What if a website refused to
explain itself to normal people?" Instead of a standard landing page
with stock photos of people pointing at whiteboards, BMO decided to
build an entire virtual Unix-like environment hidden behind a single
keyboard shortcut.

9 out of 10 visitors look at the drifting clouds, assume the developer
forgot to upload the CSS for the text, and close the tab. The 10th
visitor presses the backtick key (`) or wiggles the mouse enough to
awaken the UI, discovers a virtual filesystem, a custom Vim clone (BIM),
an asteroid arcade cabinet, and a nosy telemetry scanner, and ends up
spending 45 minutes trying to decrypt 'soul.bin'.

Built in an era where everything is generated by templates and buried
under 400 MB of 'node_modules', this project is a love letter to raw
curiosity, retro computing, and looking under the hood just for the
joy of it.

Technical Features:
- Zero-Framework Architecture: Built entirely with vanilla JavaScript,
  HTML5 Canvas, and CSS variables. Zero runtime dependencies, zero
  bundlers, and zero mercy for bloated frameworks.
- Lazy-Loaded Subsystems: The shell, BIM editor, and Space Rocks arcade
  cabinet load on demand via a single-flight module loader.
- Interactive Retro Shell: Features a persistent virtual filesystem
  (localStorage), WebAudio mechanical keyboard synthesizer, real-time
  sky/weather shaders, and cryptographic Easter eggs.

Tech stack: HTML5, CSS Variables, Vanilla JavaScript, Cloudflare Pages
Functions, WebAudio API.
